# Código de conducta

Esperamos una participación respetuosa, inclusiva y colaborativa.

No se aceptan acoso, ataques personales, discriminación, publicación de datos privados ni contribuciones deliberadamente maliciosas. Las personas mantenedoras pueden editar o cerrar contenido que incumpla estas reglas.

Para reportar un problema de conducta, contactá al mantenedor mediante un canal privado de GitHub.
